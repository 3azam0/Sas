# In-app Arabic client guide

Open **دليل الاستخدام** in the **المساعدة والمتابعة** sidebar group, or use **القائمة** on mobile to find it. Search Arabic titles, aliases and instruction text, or choose a task from its group. Within the mobile guide, **تصفح الموضوعات** reveals the topic list. Selecting a topic or a related topic clears the query, returns to its instructions and moves keyboard focus to the reading heading. No guide download/export is provided.

Use **مساعدة** in the top bar for the current screen, or in a document header for that operation. Reports also provide help for the selected report, including **مطابقة الاستهلاك** and kitchen supply. The side panel opens above the current screen/document and supports searching all topics. Closing with its button or Escape restores focus to the help trigger; it leaves draft fields and added lines intact. Ctrl/Command+Enter and Alt+Insert within help do not save or add to the underlying transaction. Native modal focus confines interaction to help while it is open.

The 24 topics cover quick start, setup, opening stock, receiving, kitchen supply/setup, recipes, completed sales imports, reports, reconciliation, offline synchronization, purchasing, returns, transfers, production, waste, balance editing, physical counts, history, troubleshooting and keyboard shortcuts. Each provides steps, an explicitly illustrative example, stock/synchronization effects, cautions and related topics. The guide describes current behavior, including selective kitchen deductions, accepted sales shortages and incomplete count-based comparisons; it now includes linked financial refunds/voids, expenses and the client acceptance walkthrough. Estimated operating results remain explicitly distinct from accounting net profit.

Printing help covers the Windows helper download/pairing, A4/80 mm selection, raster preview, job status and explicit reprints, complete document lines, current-page report details and provisional states. The content revision is 16 October 2026. It is static application content with no client records or credentials embedded. It is included in the existing web bundle/offline cache and does not extend workspace access. First enrollment/download and server transaction acceptance retain their normal connectivity requirements. Live offline-mode interaction has not been separately simulated for this release; production/offline manifests include the guide's application bundle.

Maintain content together with feature changes. Reuse the shared topic renderer and shortcut descriptions, map topics by explicit identifiers, and preserve meaningful labels and Arabic normalization. Add screenshots only where they clarify a specific task, using safe examples. Follow-up videos, interactive tours and client-specific training tracking are not part of this release.
