# الانتقال إلى اللابتوب الجديد

ابدأ من `docs/Project-Handoff-2026-11-01.md` ثم `docs/Device-Migration-2026-11-01.md`. هذه المستندات وسجل Git تحفظ قرارات العمل؛ لا تحتاج إلى نقل المحادثة لكي تواصل التطوير.

## نسخة المشروع

ثبت Git وNode.js 24، ثم نفذ:

```powershell
git clone --branch codex/recipe-forms-compatibility https://github.com/3azam0/Sas.git
cd Sas
npm install --global pnpm@11.25.0
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build:cloud
```

هذه أوامر بناء وفحص؛ النشر إجراء منفصل. آخر build حي موثق سابقًا هو `d3bf04d0f44c0f24`؛ لم يُعد فحصه أو نشره أثناء تجهيز الانتقال. افحص `/api/v1/health` قبل أي نشر لاحق.

افتح هذا المجلد كمشروعك الجديد. لا تنقل `node_modules` أو `.next` أو ملف `.git` الخاص بالـworktree القديم. ملف `project-all-refs.bundle` في الحزمة المحلية بديل مستقل في حال تعذر تنزيل GitHub:

```powershell
git clone --branch codex/recipe-forms-compatibility C:\Transfer\project-all-refs.bundle Sas
cd Sas
git remote set-url origin https://github.com/3azam0/Sas.git
git fetch origin
```

الـbundle يحفظ الفروع المحلية أيضًا. النسخة القديمة `codex/foodo-live-synced` تحتوي ثلاثة ملفات معدلة ومسودة release غير متتبعة؛ حُفظت في `older-checkout-work` مع patch. راجعها عند الحاجة على فرعها القديم، ولا تطبقها تلقائيًا فوق الفرع الحالي الذي يحتوي تغييرات أحدث.

## الملفات الخاصة

انقل حزمة `Fodo-private-transfer-2026-11-01.zip` إلى وسيط خاص موثوق، ثم افحص SHA-256 مقابل الملف المصاحب. الحزمة غير مشفرة وتحتوي بيانات موظفين وبصمات وكلمات مرور قديمة داخل النسخة الكاملة؛ لا ترفعها إلى GitHub أو تشاركها علنًا.

تتضمن الحزمة الملفات الأصلية المتاحة، القوائم النهائية، MDB المعدل، نسخة الجهاز الكاملة قبل المسح، خريطة الأكواد، تقرير التنفيذ، وأدوات العملية الخاصة. وثيقة الحزمة تبين الملفات التي تم العثور عليها فعليًا. لا تعيد تشغيل أدوات المسح؛ الجهاز جُهّز بالفعل.

## ما يلزم مراجعته قبل حذف الجهاز القديم

- تأكد أن الحزمة نُقلت وفُتحت وأن المشروع يُستنسخ على الجهاز الجديد.
- من Fodo تأكد أن العمليات كلها متزامنة، أو صدّر Recovery archive للعمليات المعلقة. هذه الجلسة لم تفحص outbox في المتصفح ولم تنقله؛ Git لا يحتويه.
- البيانات المحلية التجريبية `.data*` ليست ضمن الحزمة؛ إذا كنت تحتاج واحدة منها أوقف خادمها وأنشئ backup بالطريقة الموثقة قبل التنظيف.
- أعد تسجيل الدخول إلى الخدمات من الجهاز الجديد؛ لا تنقل credential stores أو auth.json. ملف `.env.example` مرجع فقط، وأسرار الخدمات تُستعاد من مخزنها الموثوق.
- برنامج البصمة يحتاج SDK المناسب و32-bit Windows PowerShell. ملفات تثبيت ZKTeco المحلية المتاحة مدرجة ضمن الحزمة الخاصة؛ يلزم اختبار تثبيتها وتوافقها على الجهاز الجديد.

لم تُحذف ملفات من اللابتوب القديم ولم تتم إزالة Codex أثناء تجهيز النقل.
