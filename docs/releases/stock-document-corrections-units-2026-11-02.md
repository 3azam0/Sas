# Stock document corrections and entry units

Requested scope: edit accepted opening balances, receipts and kitchen issues/transfers with retained correction history; select compatible quantity entry units throughout stock and production forms. The later request for a generic material opening-balance picker was withdrawn. Only the missing opening eligibility for **لحم بقري للفرم** is addressed; no new opening quantity is entered automatically.

Owners and managers can open an accepted document from its history and supply a correction reason. A single transaction reverses its stock effects, posts a new linked document and records the actor, reason and reversal IDs. Original documents remain unchanged. Retries use a saved operation ID to prevent duplicate posting. Tenant, generation, dates, closed periods, available stock and full ledger/layer/balance reconciliation are checked before acceptance. A failed replacement rolls back the reversal. The private correction table permits the API role to select/insert only, with forced tenant RLS.

Incoming documents with consumed source layers or later outgoing/value activity cannot be corrected through this flow. Kitchen transfers cannot be corrected after their destination stock has been used. These restrictions protect historical costing; a blocked correction changes nothing. Source location changes require a separate transfer.

Opening, receiving, kitchen issue, transfer, stock count, supplier return, balance adjustment, recipe yield, production, butchery and preparation quantity fields support compatible units and configured packs. Canonical quantities and unit costs remain in the stock unit; selecting grams for a kilogram material converts the input exactly. Invalid dimensions or conversions exceeding six canonical decimal places are rejected.

A zero balance row with no ledger history no longer prevents an initial opening document. Materials with actual stock history remain excluded. This restores eligibility for the cleared minced-beef material without weakening the duplicate-opening check.
