# Stock issue form UX — 12 October 2026

The stock issue editor is easier to scan and use on desktop and phones. Document fields share a compact section, required markers sit beside labels, and the duplicated keyboard help block is removed. Material cards pair the searchable selector with quantity/unit and a clear remove action. Each selected row shows expected available stock, remaining stock for a valid quantity and estimated average-cost value. Excessive quantities receive immediate row/field highlighting, an associated shortage description and a total-area review indicator. Optional notes retain their text when collapsed. The estimated total and save/cancel actions stay visible in a fixed footer. Small documents hide unnecessary paging controls; longer ones retain pagination. Removing the last row restores focus to a fresh selector.

The form is reused by **صرف مخزون** and the kitchen screen. Warehouse/recipient identity, quantity rules, offline capture, synchronization, actual consumption and shortage rejection remain unchanged. UI projections are display-only; valid documents still follow the existing whole-document validation and server acceptance. Estimates use current average cost and can differ from accepted FIFO cost.
